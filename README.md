# GEO-SENTINEL: Sovereign Satellite Semantic Retrieval & Multi-Temporal Change Intelligence Platform

GEO-SENTINEL is an enterprise-grade, air-gapped, on-premises Earth Observation intelligence system. It enables defense, intelligence, and environmental analysts to query massive satellite archives using free-form natural language semantics, detect multi-temporal structural and land-cover changes, suppress confounding false alarms (seasonal phenology, clouds, shadows, co-registration jitter), perform unsupervised site discovery, preserve cryptographic geospatial provenance, and incrementally ingest newly acquired GeoTIFF/COG scenes with zero downtime.

---

## 1. Core Architectural Capabilities

### 1.1 Semantic and Multimodal Retrieval (Clause 2.2.1)
- **Natural Language Semantic Search:** Maps free-text queries (e.g. *"newly built structures near a river"*, *"large vehicle concentrations on open ground"*, *"deforestation and timber logging clearance"*, *"airport runway expansion"*) into a unified 512-dimensional metric space.
- **Image-to-Image Visual Search:** Accepts uploaded tile crops or exemplars to identify visually and semantically identical locations across the archive.
- **Hybrid Multi-Factor Ranking Function:**
  $$\mathcal{S}(q, x) = w_{\text{sem}} \cdot \cos(\mathbf{e}_q, \mathbf{e}_x) + w_{\text{qual}} \cdot Q(x) + w_{\text{spat}} \cdot \text{Spatial}(AOI, x)$$

### 1.2 Multi-Temporal Change Analysis & Onset Detection (Clause 2.2.2)
- **Multi-Temporal Differencing:** Combines deep latent feature distance, structural edge divergence, and multi-spectral index deltas ($\Delta\text{NDVI}$, $\Delta\text{NDWI}$, $\Delta\text{NDBI}$).
- **Change Classification:** Automated categorization into *Construction / Built-up*, *Clearance / Deforestation*, *Water Extent Variation (Flood/Contraction)*, and *Road / Transport Infrastructure*.
- **Earliest Usable Observation ($T^*$) Estimation:** Pinpoints the exact earliest timestamp when change emerged with statistical significance ($Z(t) > 3\sigma$) on cloud-free usable imagery.

### 1.3 False-Alarm Suppression & Quality Handling (Clause 2.2.3)
- **Radiometric Normalization:** Relative Radiometric Normalization (RRN) and histogram matching over Pseudo-Invariant Features (PIFs) to eliminate illumination and sun-angle shifts.
- **Co-Registration Sub-Pixel Alignment:** Phase correlation compensation and morphological edge buffering to eliminate border jitter artifacts.
- **Multi-Spectral QA Masks:** Pixel-level screening of clouds, cloud shadows, haze, and snow.
- **Precision Confidence Scoring:**
  $$C_{\text{change}} = \text{RawMagnitude} \times \min(Q_1, Q_2) \times (1 - \text{Residual}_{\text{reg}}) \times (1 - \text{Shift}_{\text{phenology}})$$

### 1.4 Discovery and Clustering (Clause 2.2.4)
- **Unsupervised Semantic Clustering:** Groups satellite archive tiles using K-Means and density clustering in 512-dim embedding space.
- **2D UMAP/PCA Projection:** Visual interactive scatter explorer.
- **One-Click Regional Discovery:** Analyst selects any suspicious tile $\to$ instant retrieval of all identical facilities across the AOI without manual queries.

### 1.5 Analyst Workflow & STAC Provenance (Clause 2.2.5)
- **Ranked Review Queue:** Prioritized triage queue sorted by Severity $\times$ Confidence.
- **Interactive Split-Screen Swipe Inspector:** Synchronized curtain swipe, difference heatmaps, false-color NIR toggles, and time-series animation scrubber.
- **Active Learning Feedback Loop:** Analyst *Confirm* / *Reject* decisions dynamically adapt feature importance weights and persist to an immutable audit trail.
- **Cryptographic STAC Item Provenance:** Full OGC/STAC v1.0.0 compliance with SHA-256 integrity signatures and exportable intelligence reports (Markdown / PDF / GeoJSON).

### 1.6 Scale, Incremental Ingestion & Sovereignty (Clause 2.2.6 & 2.2.7)
- **100% Air-Gapped / Offline:** Zero external network calls or cloud APIs during evaluation.
- **Native GeoTIFF / COG Engine:** Preserves EPSG:4326/3857 affine transforms and coordinates.
- **Incremental FAISS Vector Indexing:** Live ingestion of newly acquired scenes without rebuilding the index or stopping the service.

## 4. Quick Start & Execution

### Prerequisites
- Python 3.10+
- PyTorch (CUDA optional but supported)
- Dependencies installed: `fastapi`, `uvicorn`, `faiss-cpu`, `rasterio`, `shapely`, `scikit-learn`, `opencv-python`, `pillow`

### Launching the System
```bash
# On Windows:
scripts\run_system.bat

# On Linux / macOS:
chmod +x scripts/run_system.sh
./scripts/run_system.sh
```

Or manually:
```bash
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```
Open your browser at: **`http://127.0.0.1:8000`**

### Running the Benchmark Suite
```bash
python scripts/benchmark_evaluation.py
```

### Running the Unit Test Suite
```bash
python -m unittest discover -s tests -p "test_*.py"
```
